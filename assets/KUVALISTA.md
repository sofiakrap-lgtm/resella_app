# Kuvalista

Tähän on listattu jokainen tiedosto, jonka demo osaa näyttää. Mitään ei ole
pakko lisätä kerralla: puuttuvan tiedoston tilalla näkyy brändin mukainen
paikkamerkki. Aloita tähdellä merkityistä, ne näkyvät demon pääpolulla.

Lisäämisen jälkeen: `npm run sync-assets` (tai käynnistä `npm run dev` uudestaan).
